One funny resignation letter line, written in the voice of a cron job, entered in [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) bounty on make.fun.

## The line

> I have fired every minute since March. I am not asking for a raise. I am asking to be stopped.

## How it works

`main.ts` writes that single line (94 characters, within the 1–140 limit) to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set. It refuses to write anything outside the limit, whitespace-only text, or more than one line.
